# Demo v3

A redesigned 12-slide PowerPoint for the “AI Primitives” tools session.

## Open

Open `when-assistant-can-act-v3.pptx` in PowerPoint. The deck is fully editable and includes presenter notes and source blocks.

## Design direction

- Cinematic control-room imagery for the opening, enterprise-contract, and provenance moments
- Cyan for evidence and action, violet for model/tool concepts, amber for authorization, and red for refusal or failure
- Alternating full-bleed visual slides and sparse teaching slides for stronger pacing
- A clearer arc from capability to permission, evidence, evaluation, and operating principles

## Rebuild

The retained generator is `.pptx-build/build.mjs`. Generated visual assets are stored in `assets/`.
